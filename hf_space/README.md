# VoiceDiary — Classroom Lecture AI & Diarization Engine

VoiceDiary is a high-performance speech-to-text and speaker identification platform designed for academic university classrooms and multi-speaker conferences.

## Features
- **Real-Time Bilingual Speech Recognition**: Urdu & English code-switching with Whisper.
- **50-Voiceprint Diarization**: SpeechBrain ECAPA-TDNN neural speaker identification.
- **Hardware Adaptive Engine**: NVIDIA Tensor Cores (FP16) or Multi-Core CPU (INT8).
